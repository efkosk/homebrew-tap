# efkosk/tap

Homebrew tap for [EFClip](https://efclip.app/), a clipboard history for the Mac menu bar that syncs with the EFKey keyboard on iPhone.

```sh
brew install --cask efkosk/tap/efclip
```

EFClip updates itself through Sparkle, so `brew upgrade` skips it unless you pass `--greedy`. The cask follows new releases automatically.

Requires macOS 14 or later on Apple Silicon.
